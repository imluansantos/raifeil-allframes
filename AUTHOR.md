# Autor

Este projeto foi desenvolvido por **Luan Santos**, através da **Lunding Technology**.

## Sobre o autor

Luan Santos é o desenvolvedor responsável pela Lunding Technology (lunding.com.br), empresa que cuidou de todo o desenvolvimento deste site: da estrutura de código até os detalhes finos de experiência do usuário.

O próprio projeto já é um retrato desse cuidado. É um site multilíngue (português, inglês, espanhol, alemão e italiano), com configurações reais de preferência do usuário (tema claro/escuro, nível de animação, cursor personalizado), consentimento de cookies funcional, imagens e vídeos otimizados para carregar rápido, e uma base de SEO estruturada (meta tags por página, sitemap, Open Graph). Tudo pensado nos detalhes, não só para "funcionar".

## Projeto

- Cliente: All Frames Technology (Bento Gonçalves/RS)
- Ano: 2026
- Tempo de desenvolvimento: 3 semanas

## Stack utilizada

- React 19
- TanStack Start e TanStack Router (roteamento baseado em arquivos)
- TanStack Query
- Tailwind CSS v4
- GSAP e Motion (animações)
- TypeScript
- Vite (build) e Nitro (servidor)
- ESLint e Prettier
